# Telegram Mini App

Простое Telegram Mini App на Next.js, которое показывает информацию о пользователе.

## Запуск локально

```bash
npm install
npm run dev
```

Откройте [http://localhost:3000](http://localhost:3000) в браузере.

## Деплой на Vercel

1. Загрузите проект на GitHub
2. Импортируйте в Vercel
3. Vercel автоматически определит Next.js и задеплоит приложение

## Настройка Telegram Bot

1. Создайте бота через [@BotFather](https://t.me/BotFather)
2. Используйте команду `/newapp` для создания Mini App
3. Укажите URL вашего Vercel приложения
4. Протестируйте через Telegram

## Технологии

- Next.js 15
- TypeScript
- Tailwind CSS
- @telegram-apps/sdk-react
